# Changelog

All notable changes to the Multi-Agent Job Application System will be documented in this file.

## [1.0.0] - 2025-11-10

### Added
- Initial release of Multi-Agent Job Application System
- Job Fetching Agent for scraping profesia.sk
- CV Tailoring Agent with LLM-powered customization
- Critique Agent for CV quality review
- Notification Agent with email support
- Job history tracking and deduplication
- Comprehensive configuration system (YAML/JSON)
- Logging and error handling
- Cron-compatible scheduling
- Python scheduler as alternative to cron
- Statistics and reporting
- Manual review mode
- Setup and installation scripts
- Comprehensive documentation

### Features
- Automated job searching with keyword and location filtering
- AI-powered CV tailoring for each job posting
- Intelligent CV critique with quality scoring
- Email notifications with tailored CVs attached
- Job application history tracking
- Duplicate job detection
- Configurable match scoring
- Daily statistics and reporting
- Export history to CSV
- Test mode for configuration validation

### Documentation
- Comprehensive README with installation and usage instructions
- Quick Start guide for fast setup
- Example configuration files
- API documentation in code
- Setup script with detailed instructions

### Technical
- Modular architecture with separate agent classes
- Clean separation of concerns
- Robust error handling and logging
- Environment variable support
- Virtual environment support
- Unit tests for core functionality
- Type hints throughout codebase
